# DX Performance Mapping Generator for STD 205

This project provides tools to generate and validate **ASHRAE Standard 205-compliant performance maps** for DX (Direct Expansion) air conditioning units using curve-based performance data. It implements a full workflow from raw curve data to structured JSON outputs, schema validation, and optional conversion to Excel format.

---

## 📌 Features

* Generates performance curves from code-based equations (via Jupyter Notebook or script).
* Loads and parses performance curves from a CSV file.
* Computes cooling performance over a grid of conditions defined in a JSON template.
* Supports various curve types: **linear, quadratic, cubic, bi-quadratic**.
* Uses **PsychroLib** for accurate psychrometric calculations.
* Estimates sensible cooling capacity from total capacity.
* Saves computed results into a structured JSON format compliant with ASHRAE Standard 205.
* Validates generated JSON against the **RS0004** and **ASHRAE205** schemas.
* Converts JSON results to **Excel (XLSX)** format using [Toolkit 205](https://github.com/open205/toolkit-205).

---

## 📂 File Structure

* `input/`  
  → Place JSON files here for conversion (e.g., `DX_Updated_STD205_Output.json`).

* `xlsx/`  
  → Output folder where converted XLSX files will be saved.

* `unitary_dx_at_code_curves.ipynb`  
  → Jupyter notebook that demonstrates generating a CSV of performance curves.

* `unitary_dx_capacity_curves.csv`  
  → Example CSV file containing performance curves (generated by the notebook).

* `DX-Constant-Efficiency.RS0004.a205.json`  
  → Template JSON defining the variable grid and structure for performance mapping.

* `generate_performance_map.py`  
  → Main script: generates CSV, computes performance map, fills the template JSON, validates, and (optionally) converts JSON to XLSX.

* `DX_Updated_STD205_Output.json`  
  → Example output JSON with completed lookup tables.

## 📥 Requirements

Install dependencies:

```bash
pip install pandas numpy matplotlib psychrolib jsonschema tk205
````

For JSON → XLSX conversion using Toolkit 205, follow setup at [Toolkit 205](https://github.com/open205/toolkit-205), then build schemas:

```bash
poetry run doit build_schema
```

---

## 🧠 Workflow

1. **Generate Curves**
   Use `unitary_dx_at_code_curves.ipynb` or the first part of `generate_performance_map.py` to generate `unitary_dx_capacity_curves.csv`.

2. **Map to JSON**
   `generate_performance_map.py` reads the CSV, applies modifier curves, computes capacity & power, and writes results into the template JSON.

3. **Validation**
   The script validates the JSON against the official **RS0004** and **ASHRAE205** schemas.

4. **Conversion** (optional)
   With Toolkit 205 installed, the script (or `tk205.translate_directory`) converts the JSON into an Excel `.xlsx` file.

## ⚙️ Configuration

Key parameters (inside `generate_performance_map.py`):

```python
csv_file = "unitary_dx_capacity_curves.csv"
json_template_file = "DX-Constant-Efficiency.RS0004.a205.json"
output_json_file = "DX_Updated_STD205_Output.json"

nominal_capacity = 232057  # W
nominal_eer = 9.2
nominal_SHR = 0.7
```


---

## ⚠️ Notes

* Script assumes **PLR = 1.0** (part-load ratio fixed).
* Sensible capacity estimation is simplified (constant SHR, can be improved with ADP model).
* Curve types must be one of: `bi_quad`, `cubic`, `quadratic`, `linear`.
* Validation requires **RS0004.schema.json** and **ASHRAE205.schema.json** present in the working directory.
